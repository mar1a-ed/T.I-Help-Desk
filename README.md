# T.I Help Desk

### Esta API simula um sistema Help Desk de suporte em T.I (Tecnologia da Informação) 👩‍💻✅⛔

#### Principais Funções:
- `Resolução de Problemas`: Organizar e especificar soluções de problemas comuns no mundo da informática
- `Tickets`: Acompanhar as solicitações dos usuários para solucionar seus empecilhos
- `Suporte em Níveis de Prioridade`: Organiza os níveis dos problemas solicitados pelos usuários por níveis de infraestrutura, como por exemplo:
  - `Baixa Prioridade`: Problemas básicos
  - `Média Prioridade`: Problemas Moderados
  - `Alta Prioridade`: Problemas avançados
